# Deterministic Neural Video Codec

## Project Status

Phase I: deterministic scope and provenance.

This repository is an engineering reconstruction of a deterministic INT16
runtime for a DCVC-RT-family neural video codec. The project treats FP16 as the
fast deployment profile and INT16 as the interoperability profile for
cross-device bitstream consistency.
